### 第一步 解压下载好的游戏本体  
>
>[!NOTE]
>无需严格根据步骤来，合理安排时间有助于提高效率  
>解压密码是→**tsukihime3**←  
>文件很大，故解压时间很长，可以点击后台解压，然后先去下一步  
>(**确保所有分卷下载完整**)  

#### 如从Touchgal盘（浏览器）下载

打开**ZArchiver**(初始界面就是根目录)→找到**Downloads**文件夹，目录下有您下载的文件→所有分卷下载完成后，单击其中一个解压即可  
(这里推荐将游戏本体文件移动到一个好找的文件夹, 可以自己新建一个)  

#### 如从百度网盘下载

打开**ZArchiver**→找到**Downloads**文件夹→找到**BaiduNetdisk**文件夹→找到全部分卷压缩包并解压  

解压完成后**先测试能否识别**游戏，识别成功后可以删除压缩包以节省储存空间（注意别把游戏本体删了）  

### 第二步 安装模拟器并配置  

1. 打开模拟器  
2. 安装密钥与固件  
这里会调用系统原生的“文件”应用，点击**左上角三条杠**，再点击**手机名称**便可进入主目录  
文件目录与第一步相同  
如果您是在**GitHub**下载的，会直接存放在*Downloads*文件夹下  
如果您是在**123盘**下载的，文件就在*根目录/123盘*目录下  
3. 挂载游戏目录  
与第一步相同，找到存放游戏的目录  
你也可以新建文件夹，将游戏文件拷贝到便于查找的地方  
确保此目录下有游戏本体文件后点击**使用此文件夹**  

识别到游戏后，看看能不能正常打开游戏  
正常应该看到日文的开场动画  
注: 开场不能跳过:spoiler[（是个视频]  

### 第三步 安装汉化补丁  

1.先解压下载好的汉化补丁压缩包  
使用ZA找到压缩包→单击→解压到此文件夹  
2.打开模拟器→在首页长按游戏找到附加项→右下角安装→选择mod与金手指→找到你解压好的汉化补丁→点进去找到目录下有exefs,romfs,config.ini,icon.jpg四个文件夹或文件的目录→点击使用此文件夹→等待安装成功  

### 第四步 安装固件（如果第二步未安装）

不安装固件会导致少许文字口口  
下载完成后无需解压  
安装方法：设置→管理所有数据→安装固件（此时调用手机原生文件应用）→左上角三条杠点手机名称进入主目录→找到您的固件并导入firmware.zip文件

#### 常见问题Q&A

1.**全都要下载吗？**  
是的，所有分卷都要下载！  
2.**怎么解压啊？/这些文件要一个一个解压吗？**  
全部下载完后单击其中一个压缩包，点击 解压到此文件夹 就可以了  
这是分卷压缩，所以不能一个一个解压  
点一个解压相当于把所有的压缩包都整合起来解压了  
3.**安装模拟器时显示解析安装包时错误？**  
Suyu安装包仅支持安卓11及以上~  
4.**我还想添加游戏，应该在哪添加呢？**  
设置-管理游戏文件夹-右下加号  
5.**魔夜/FSN/FHA打上汉化了，怎么还是英文的？**  
要进游戏手动切换  
(考验你英语水平的时候到了)  
6.**在哪存档？**  
Y键  
7.**虚拟按键怎么调整？按键震动怎么关闭？**  
进游戏按手机返回键调出菜单，找到虚拟按键，下滑找到触摸反馈(就是震动)，关闭即可  
其他选项就可以调整按钮  
8.**月姬R开场怎么按键没反应？**  
不能动的哦(是个视频且不能跳过)

## 关于手动构建

我只缓慢分发arm64-v8a的版本  
如果您的设备架构不同或想及时用上最新版本，可以自行手动构建  
从[官网仓库](https://git.eden-emu.dev/eden-emu/eden/src/branch/master/docs/build/Android.md)克隆到本地  
补全所指示的依赖到Android Studio并修改这个文件  
- src/video_core/texture_cache/util.cpp  
把大约在126行的代码  

```cpp
.depth = level == 0 && num_levels == 1
                     ? block_size.depth
                     : AdjustMipBlockSize<GOB_SIZE_Z>(num_tiles.depth, block_size.depth, level),
```

改为  

```cpp
.depth = AdjustMipBlockSize<GOB_SIZE_Z>(num_tiles.depth, block_size.depth, level),
```

删除171-177行（经过上一步修改）  
上一行是  

```cpp
[[nodiscard]] constexpr Extent3D TileShift(const LevelInfo& info, u32 level) {
//删掉以下代码，上面别删
    if (level == 0 && info.num_levels == 1) {
        return Extent3D{
            .width = info.block.width,
            .height = info.block.height,
            .depth = info.block.depth,
        };
    }
//注意别删多或删少了
```

将1310~1312行  

```cpp
static_assert(CalculateLevelSize(LevelInfo{{32, 32, 1}, {0, 0, 4}, {1, 1}, 4, 0, 1}, 0) == 0x40000);

static_assert(CalculateLevelSize(LevelInfo{{128, 8, 1}, {0, 4, 0}, {1, 1}, 4, 0, 1}, 0) == 0x40000);
```

改为  

```cpp
static_assert(CalculateLevelSize(LevelInfo{{32, 32, 1}, {0, 0, 4}, {1, 1}, 4, 0}, 0) == 0x4000);
```

然后按需构建即可  
（大概同样适用于PC, Linux等
